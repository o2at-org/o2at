# Contributing to O2AT

O2AT is an engineering proposal under review. Use the public issue tracker for technical review and reproducible defects.

Every report should state:

1. The source version and SHA-256.
2. The exact section, table, descriptor or test vector.
3. The observed problem and evidence needed to reproduce it.
4. A proposed change and the effect on existing implementations.
5. Whether the proposal changes on-wire interpretation or endpoint admission.

Keep editorial suggestions distinct from protocol changes. Do not submit confidential information or third-party material that you are not authorised to publish. A pull request or issue is a proposal, not an adopted protocol change. The project will record accepted changes in a numbered revision and update compatibility notes and vectors.

The website and O2AT specification, future RTL, hardware design and referenced third-party works have separate licensing terms. Do not assume one licence covers every contribution.
